# c2 · 第二章 导数与微分（期中 45%）

**出口能力**：给一个复合/隐式/参数式表达的函数，能在 3 分钟内求出指定阶的导数；能写出某点处的切线方程；能判断一个分段函数在某点的可导性。
**复用点**：p0（题型手册的模板 3–5）、c1（导数定义是极限）、c3（洛必达、单调性、极值全依赖求导）、c4（凑微分是链式法则的逆运算）、c5（变限积分要求导）。
**贯穿样本**：

| 样本 | 用到它的节 | 每一次施加什么 |
| --- | --- | --- |
| $f(x)=\lvert x\rvert$ | 2.1、2.2 | 先用定义算左右导数，再当作"连续不可导"的标准反例 |
| $x^2\sin\dfrac1x$ | 2.2、2.8 | 先当"可导但导数不连续"的反例，再完整讨论可导性 |
| $\ln(1+x^2)$、$\sin(e^x)$、$\ln\dfrac{1-\sqrt x}{1+\sqrt x}$ | 2.3 | 一次比一次多一层复合 |
| $xe^x$、$x^2\sin x$ | 2.4 | 高阶导数，每阶都要先提公因式 |
| $x^2+xy+y^2=3$ | 2.5、2.8 | 先求 $y'$，再在 $(1,1)$ 处写切线 |
| $x=t^2,y=t^3$ | 2.6 | 一阶 → 二阶，二阶分母是 $x'(t)$ |
| $x^x$ | 2.7 | 幂指函数，取对数 |
| $y=x\ln x$ | 2.8 | 切线 + 法线 |

| 节 | 锚点结果 | 机制一句话 | 速查 | 题 |
| --- | --- | --- | --- | --- |
| 2.1 导数的定义 | 用定义算 $x^2$ 在 1 的导数为 2 | 差商的极限；分母与分子跨度必须匹配 | 六条变形公式 | 2.1-01、02、03 |
| 2.2 可导/连续/可微 | $\lvert x\rvert$ 在 0 连续但不可导 | 可导 ⟹ 连续；可导 ⟺ 可微 | 关系图 + 反例库 + 条件判断法 | 2.2-01、02 |
| 2.3 求导法则 | $\left[\ln(1+x^2)\right]'=\dfrac{2x}{1+x^2}$ | 链式法则：由外向内，逐层乘导 | 求导表 + 三类分解示例 | 2.3-01~04 |
| 2.4 高阶导数 | $(xe^x)''=e^x(x+2)$ | 逐阶求，每阶提公因式 | $n$ 阶公式表 + 二阶速查 | 2.4-01、02 |
| 2.5 隐函数求导 | $x^2+xy+y^2=3$ 的 $y'=-\dfrac{2x+y}{x+2y}$ | 两边对 $x$ 求导，遇 $y$ 乘 $y'$ | 常见项求导表 + 三种问法 | 2.5-01、02、03 |
| 2.6 参数方程 | $x=t^2,y=t^3$：$\dfrac{dy}{dx}=\dfrac{3t}2$，$\dfrac{d^2y}{dx^2}=\dfrac{3}{4t}$ | 二阶 = 对 $t$ 求导再除 $x'(t)$ | 公式 + 二阶分母对照 | 2.6-01、02、03 |
| 2.7 对数求导法 | $(x^x)'=x^x(\ln x+1)$ | 取对数 → 求导 → 乘回 | 常用结果 + 对数性质 | 2.7-01、02 |
| 2.8 微分与切线 | $y=x\ln x$ 在 1 的切线 $y=x-1$ | $dy=f'(x)dx$；切线用点斜式 | 切线/法线公式 + 四个动作 | 2.8-01、02、03 |
