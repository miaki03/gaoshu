# c1 · 第一章 函数与极限（期中 48%）

**出口能力**：给一个函数，能算出定义域、判断间断点类型、算出极限、判断零点所在区间；给一个含参数的式子，能用"连续"或"极限存在"反解参数。
**复用点**：p0（公式卡与题型手册）、c2（导数定义要用极限、复合求导要用 1.1）、c3（中值定理要用连续与极限）、c4（换元要用复合）、c5（变限积分要用连续）。
**贯穿样本**：一组固定函数，从 1.1 用到 1.7——

| 样本 | 用到它的节 | 每一次施加什么 |
| --- | --- | --- |
| $f(x)=\dfrac{x}{1-x}$ | 1.1 | 复合代入 $f(f(2))$ |
| $\dfrac{\sin n}{n}$ | 1.2 | 夹逼，证极限为 0 |
| $f(x)=\begin{cases}\sin x & x<0\\ a-\arccos x & x\ge0\end{cases}$ | 1.3、1.6 | 先求左右极限，再由连续定 $a$ |
| $\dfrac{\sin 3x}{x}$、$(1+2x)^{1/x}$ | 1.4 | 凑第一个 / 第二个重要极限 |
| $\dfrac{1-\cos x}{x\sin x}$、$\dfrac{\tan x-\sin x}{x^3}$ | 1.5 | 直接替换 / 加减抵消后升阶 |
| $\dfrac{\lvert x\rvert}{x}$、$\dfrac1x$、$\sin\dfrac1x$ | 1.6 | 四类间断点各占一个 |
| $x^3+2x-1$ | 1.7 | 端点代入看异号，再证介值 |

| 节 | 锚点结果 | 机制一句话 | 速查 | 题 |
| --- | --- | --- | --- | --- |
| 1.1 函数与初等函数 | $f(x)=\dfrac{x}{1-x}$ 时 $f(f(2))=-\dfrac23$ | 定义域三条限制取交集；同一函数要定义域与法则都同 | 基本初等函数表 + 定义域陷阱 | 1.1-01、1.1-02 |
| 1.2 数列的极限 | $\dfrac{\sin n}{n}\to0$，靠夹逼 | 收敛必有界，有界不一定收敛 | 常用数列极限 + 有理分式判定 | 1.2-01、02、03 |
| 1.3 函数的极限 | $\dfrac{\sqrt{1+x}-1}{x}\to\dfrac12$ | 极限存在 ⟺ 左右相等；分母趋零则分子必趋零 | 左右极限判定表 | 1.3-01、02、03 |
| 1.4 两个重要极限 | $\lim\dfrac{\sin x}{x}=1$，$\lim(1+2x)^{1/x}=e^2$ | 第一个靠"凑"，第二个靠"化 1 加无穷小" | 导出结果表 + $1^\infty$ 速判 | 1.4-01、02、03 |
| 1.5 无穷小 | $\lim\dfrac{1-\cos x}{x\sin x}=\dfrac12$ | 乘除能替换，加减抵消必须升阶 | 一阶/三阶等价表 + 三条纪律 | 1.5-01、02、03 |
| 1.6 连续与间断点 | $\dfrac{\lvert x\rvert}{x}$ 在 0 是跳跃间断点 | 连续 = 左极限 = 右极限 = 函数值 | 四分类判定流程 | 1.6-01、02、03 |
| 1.7 闭区间连续性质 | $x^3+2x-1$ 在 $(0,1)$ 有零点 | 三定理同一前提：闭区间 + 连续 | 三定理条件对照 + 证明三步 | 1.7-01、02 |
