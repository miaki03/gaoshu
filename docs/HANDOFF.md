## 5. 关键决策与理由（别推翻，除非有更好的理由）

| 决策 | 理由 |
| --- | --- |
| **不用 Hugo，自写 Node 生成器** | Windows 无 hugo，WSL 被沙箱挡住（`E_ACCESSDENIED`）；且学习站需要进度/错题本/搜索等交互，主题改造比自写更费 |
| 构建期渲染 KaTeX | 无 CDN 依赖、离线可读、无 FOUC。`output: 'html'`（不用 htmlAndMathml）是为了把 500KB 的真题页 DOM 减半 |
| 只完整转录 2025 一份真题 | 原卷公式是 MathType OLE + WMF，逐字打字有出错风险；其余三年给逐题考点 + 原卷下载，宁可给原件 |
| 不写 Ch3–5 正文 | 不在期中范围，写了等于浪费考前几天 |
| 冲刺层与学习层分开 | 冲刺层给模板/真题（为了拿分），学习层给推导（为了学会）。混在一起会让"救急"变成"从头学" |
| 每道题必须有 `verify` | 人手写答案早晚错一处，学生无法判断错在哪。`check.mjs` 强制这个字段 |
| 概念台账 | 唯一的自动漂移检测器：概念被别的节"偷改定义"时会报错 |

## 6. 环境坑（会重复踩的）

1. **pip 装不了包**：pip 的临时目录权限被沙箱拒（`tempfile.mkdtemp` 建的目录写不进去）。一律用 Python 标准库。
2. **PowerShell 5.1 `Set-Content -Encoding utf8` 写 BOM**，会毁掉 front matter 的 `---`，整页静默不参与构建。改文件用
   `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))`。
3. **`$home` 是只读自动变量**（PowerShell 变量名大小写不敏感）。用 `$homePath`。
4. **git push 需要完全权限**：沙箱内 git spawn ssh 被拒（`couldn't create signal pipe`）。
5. **push 必须用 `id_ed25519_mephisto`**：默认的 `id_ed25519` 是只读 deploy key（HugoPerson/HugoPoster），会报 `denied to deploy key`。
6. **远端是 `ssh://git@ssh.github.com:443/...`**：22 端口不通；`core.sshCommand` 指向 `.tmp/ssh_config`（内含代理与 key）。这个文件在 `.tmp/`（gitignored），换机器要重建。
7. **无法截图**：Edge headless 也被沙箱挡（mojo 命名管道）。只能靠 HTML 结构与链接校验 + 剥标签读纯文本。
8. **提交信息含中文引号/特殊字符时用 `-F 文件`**：PowerShell 会把消息里的 `"` 当字符串结束。
