# 关于与来源

## 这个站是什么

一套面向**单人自学**的高等数学 A-1 教材站，同时服务两个目标：把期中考试的分数拿回来，以及把课真正补上。

方法论来自一份与学科无关的教学设计文档（PLAYBOOK）：每个 Part 是一个能力阶层，每个章是验收单位，每节是 15–25 分钟的交付原子，固定四件套——**锚点结果 / 机制 / 速查 / 题**。所有知识性断言尽量做到可核对。

## 内容来源

| 内容 | 来源 |
| --- | --- |

| 章节正文、公式卡、题型模板 | 依据上述范围自行撰写，配合通用教材（同济《高等数学》上册）的标准结论 |
| 练习题与答案 | 自编；52 条直接机器复算、14 条等价界定、9 条人工核对 |

原始资料随站提供下载，放在真题页里（原卷 + 参考答案 + 大纲 + 进度表）。**如果你的资料与原文冲突，以原文为准。**

## 答案是怎么验的

站内每道题都登记在题库（`kb/problems*.json`、`kb/examples.json`）里，每条包含一个 `verify` 字段——一段可执行的 Python 表达式。但**验证强度分三级**，必须如实说：`numeric` 直接算出答案并与 `answer` 比对（52 条）；`proxy` 验的是等价命题或不等式界，没有直接算出答案（14 条）；`manual` 只是形式化检查，答案靠人工核对（9 条）。`scripts/verify.py` 会把三类数量打印出来。

```bash
python scripts/verify.py
```

复算用的是数值方法（数值极限、数值导数、数值积分），容差 $10^{-6}$。这样做的原因很直接：**只靠人写答案，早晚会错一处，而学生没法判断是哪一处错了**。

:::conv
复算只覆盖**登记进题库的题**（`kb/problems*.json`）。正文"机制"里随手举的例子不在此列，靠人工核对——所以这里的说法是"题库内的答案与正文一致"，而不是"整站零错误"。发现问题请直接改正文并把它补进题库。
:::

少数题目没有解析解（如某些参数方程、隐函数），复算时会用等价形式验证：例如隐函数题会把方程解成显式分支再数值求导，参数方程题会消去参数后验证。

## 结论的可靠程度

| 级别 | 含义 | 本站的处理 |
| --- | --- | --- |
| A | 机器可复算 | 登记 `verify`，每次改动都跑一遍 |
| B | 人能按写明的步骤核对 | 正文里给出完整推导或可代值验证的结果 |
| C | 只能人判断 | 不作为正文结论出现 |

## 数据与隐私

- 进度与错题本存在浏览器的 `localStorage` 里，**不上传、不统计、不需要登录**；
- 换设备时用进度页的「导出 / 导入」搬运 JSON；
- 站点没有第三方分析脚本、没有 cookie、没有外链字体（公式字体随站点打包，离线可用）。

## 已知的局限

1. **真题只完整转录了 2025–2026 一份**。其余三年给的是逐题考点清单与原卷下载——因为原卷公式是 MathType 嵌入对象，手工转录有出错风险，宁可给出原件。
2. **期中的范围只有第一、二章**。第三章之后的内容在「[期末续学](/s/roadmap)」里只列了路线，正文等期中考完再写。
3. 数值复算对"振荡型"极限（如 $\sin\frac1x$）不适用，这类题改用不等式界验证，边界略弱于解析证明。
4. 题目难度标"易 / 中 / 难"是主观判断，参考了大纲的难度系数分布，不是官方标注。

## 技术说明

- 静态站，零前端框架；公式在**构建时**用 KaTeX 渲染成 HTML，页面不依赖外部 CDN；
- 构建脚本 `scripts/build.mjs`（Node，无依赖框架，只用到 `marked` 与 `katex`）；
- 构建时会检查所有内部链接，坏链接直接报出来；
- 题库复算 `scripts/verify.py`（Python 标准库，无第三方依赖）。

```bash
node scripts/build.mjs      # 构建到 dist/
python scripts/verify.py    # 复算全部题目答案
```
