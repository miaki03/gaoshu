## 锚点结果

两个结果：

1. $\lim\limits_{x\to0}\dfrac{\sqrt{1+x}-1}{x}=\dfrac12$。方法是**有理化**，不是等价无穷小（等价无穷小要等 1.5 节）。
2. 若 $\lim\limits_{x\to0}\dfrac{e^{x}-a}{x}$ 存在，则 $a=1$。理由是分母趋于 $0$，而整体要有有限极限，**分子必须也趋于 $0$**。

第 2 条是填空题的常客。它的判据只有一句：$\dfrac{0}{0}$ 型才可能收敛到有限数。

## 机制

### 左右极限

$x\to x_0^-$ 表示 $x$ 从**小于** $x_0$ 的一侧趋近（左极限），$x\to x_0^+$ 表示从大于的一侧趋近（右极限）。

$$
\lim_{x\to x_0}f(x)\ \text{存在}\iff \lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)\ \text{且都是有限数}
$$

这一条是"分段函数在分界点"与"含绝对值"两类题的**唯一**着手点。

语言上的对应：$x\to0^-$ 时 $\lvert x\rvert=-x$，$x\to0^+$ 时 $\lvert x\rvert=x$；$x\to0^-$ 时 $\dfrac1x\to-\infty$，$x\to0^+$ 时 $\dfrac1x\to+\infty$。

:::trap
$\lim\limits_{x\to0}\dfrac1x$ 不存在，但**不是**因为"算不出来"，而是因为左右极限分别是 $-\infty$ 与 $+\infty$，不相等。答题时写"极限不存在"不够，要写出左右极限各自是什么。
:::

### 有理化：遇到根号差的标准动作

$\sqrt{A}-\sqrt{B}$ 型的做法：分子分母同乘 $\sqrt{A}+\sqrt{B}$，用平方差把根号消掉。

$$\frac{\sqrt{1+x}-1}{x}=\frac{(\sqrt{1+x}-1)(\sqrt{1+x}+1)}{x(\sqrt{1+x}+1)}=\frac{(1+x)-1}{x(\sqrt{1+x}+1)}=\frac{1}{\sqrt{1+x}+1}$$

令 $x\to0$，得 $\dfrac12$。

### 已知极限存在，求参数

判据：设 $\lim\limits_{x\to x_0}\dfrac{P(x)}{Q(x)}$ 存在且 $Q(x_0)=0$，则必有 $P(x_0)=0$。

原因：若 $P(x_0)\neq0$，则分子趋于一个非零数、分母趋于 $0$，比值趋于无穷，极限不存在。

**固定动作**：

1. 找出让分母为 $0$ 的点 $x_0$；
2. 令分子在 $x_0$ 处为 $0$，得到关于参数的方程；
3. 解出参数后再回代，求出极限值（题目若问极限，就要算）。

例：$\lim\limits_{x\to1}\dfrac{x^2+ax+b}{x-1}=3$，求 $a,b$。

分母在 $x=1$ 处为 $0$，故分子在 $x=1$ 处为 $0$：$1+a+b=0$，即 $a=-1-b$。

于是把分子因式分解。两根之**积**为 $b$、之和为 $-a$；已知一根是 $1$，设另一根为 $r$，则 $1\cdot r=b$，即 $r=b$。所以

$$x^2+ax+b=(x-1)(x-b).$$

约去 $x-1$ 后

$$\lim_{x\to1}(x-b)=1-b=3\ \Longrightarrow\ b=-2,\quad a=-1-(-2)=1 .$$

**代回验算**：$x^2+x-2=(x+2)(x-1)$，故 $\dfrac{x^2+x-2}{x-1}=x+2\to3$ ✓

<!-- ex: 1.3-04 -->

:::trap
两根之积为 $b$ 时，因式分解是 $(x-1)(x-b)$，**不是** $(x-1)(x+b)$。写成后者会得到 $b=2,a=-3$，代回极限是 $-1$ 而不是 $3$——整题错。**分解完展开一遍，核对常数项是不是 $b$。**
:::

### 无穷小与无穷大

- $\alpha$ 是无穷小：$\lim\alpha=0$；
- $\alpha$ 是无穷大：$\lvert\alpha\rvert\to+\infty$；
- 两者互为倒数关系（在同一个极限过程中）：$\alpha$ 是无穷小（$\alpha\neq0$）$\iff$ $\dfrac1\alpha$ 是无穷大。

:::conv
"无穷大"不是一个数，是**发散**的一种描述。写 $\lim f=\infty$ 时，标准含义是"极限不存在，但绝对值无限增大"。严格说它是"不存在"的一个子类，但在做题时可以直接写 $\infty$。
:::

### 极限的局部性质

| 性质 | 内容 | 用途 |
| --- | --- | --- |
| 局部有界性 | 若 $\lim f$ 存在，则 $f$ 在 $x_0$ 的某去心邻域内有界 | 证明题里用 |
| 局部保号性 | 若 $\lim f=A>0$，则在 $x_0$ 附近 $f(x)>0$ | 判断符号 |
| 唯一性 | 极限若存在则唯一 | 反证法 |

## 速查

### 左右极限判定表

| 现象 | 结论 |
| --- | --- |
| 左右极限都存在且相等 | 极限存在，等于该值 |
| 左右极限都存在但不相等 | 极限不存在（跳跃） |
| 一个为 $+\infty$、一个为 $-\infty$ | 极限不存在（无穷型） |
| 一个不存在且不是 $\infty$（如 $\sin\frac1x$） | 极限不存在（振荡） |

### 常见"趋于无穷"的点

| 函数 | 发散点 |
| --- | --- |
| $\dfrac1x$ | $x=0$ |
| $\tan x$ | $x=\frac{\pi}{2}+k\pi$ |
| $\ln x$ | $x\to0^+$（但 $x\to0^-$ 时无定义） |
| $\dfrac{1}{\sin x}$ | $x=k\pi$ |

## 题

:::problem id=1.3-01 level=易 source="本站自编"
求 $\lim\limits_{x\to0}\dfrac{\sqrt{1+x}-1}{x}$。

:::ans
分子有理化：同乘 $\sqrt{1+x}+1$，

$$\lim_{x\to0}\frac{(1+x)-1}{x(\sqrt{1+x}+1)}=\lim_{x\to0}\frac{1}{\sqrt{1+x}+1}=\frac12 .$$

**复算**：`1.3-01` 的 verify 用数值极限复算，得 $0.5$。
:::
:::

:::problem id=1.3-02 level=中 source="本站自编"
求 $\lim\limits_{x\to1}\dfrac{x^2-1}{x^2-3x+2}$。

:::ans
分母 $x^2-3x+2=(x-1)(x-2)$，分子 $x^2-1=(x-1)(x+1)$。约去 $(x-1)$：

$$\lim_{x\to1}\frac{x+1}{x-2}=\frac{2}{-1}=-2 .$$

**复算**：`1.3-02` 的 verify 得 $-2$。

:::trap
约分前要先确认分子分母在 $x=1$ 处都为 $0$（这是 $\frac00$ 型，约分才合法）。若分母不为 $0$，直接代值就行，约分反而会把答案改掉。
:::
:::
:::

:::problem id=1.3-03 level=中 source="2024–2025 期中 · 填空 4 同类"
若 $\lim\limits_{x\to0}\dfrac{e^{x}-a}{x}$ 存在（有限），求 $a$。

:::ans
分母 $\to0$。要使整体极限为有限数，分子必须也 $\to0$：

$$e^{0}-a=0\ \Longrightarrow\ a=1 .$$

回代验证：$\lim\limits_{x\to0}\dfrac{e^x-1}{x}=1$，存在。

**判据**：$\dfrac{\cdot}{0}$ 型，只有 $\dfrac00$ 才可能有限。
:::
:::
