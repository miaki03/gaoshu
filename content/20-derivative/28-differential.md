## 锚点结果

$y=x\ln x$ 在 $x=1$ 处：

- 切点 $(1,0)$
- 斜率 $k=y'(1)=\ln1+1=1$
- **切线** $y=x-1$
- **法线** $y=-x+1$

四行字，4 分到手。四年真题里"求切线"出现了**四次**（单选与解答题都有），是第二章里最稳的送分点。

## 机制

### 微分是什么

设 $y=f(x)$，当 $x$ 有增量 $\Delta x$ 时，$y$ 的增量为

$$\Delta y=f(x+\Delta x)-f(x)=f'(x)\,\Delta x+o(\Delta x) .$$

其中 $f'(x)\Delta x$ 是关于 $\Delta x$ 的**线性主部**，把它定义为**微分**：

$$dy=f'(x)\,dx\qquad(\text{取 } \Delta x=dx)$$

所以：**求微分 = 先求导，再在后面乘一个 $dx$。**

### 可微与可导的关系

| 命题 | 成立？ |
| --- | --- |
| 可微 $\iff$ 可导 | ✔（一元函数） |
| 可微 $\Rightarrow$ 连续 | ✔ |
| 连续 $\Rightarrow$ 可微 | ✘ |

这条在 2.2 节已经背过，选择题里常拿它设陷阱。

### 一阶微分形式不变性

无论 $u$ 是自变量还是中间变量，都有

$$dy=f'(u)\,du .$$

这条让你可以"把 $dx$ 当成一个整体符号"，求微分时不必区分变量。例：

$$d(\sin x)=\cos x\,dx,\qquad d\left(e^{x^{2}}\right)=2xe^{x^{2}}dx .$$

### 切线方程

点 $(x_0,y_0)$ 是切点时：

$$\boxed{y-y_0=f'(x_0)\,(x-x_0)}$$

**四个动作**：

1. 算 $y_0=f(x_0)$，得切点；
2. 求导 $f'(x)$；
3. 代 $x_0$ 得斜率 $k=f'(x_0)$；
4. 写点斜式，最后整理成 $y=kx+b$ 或一般式。

### 法线方程

法线与切线**垂直**，斜率乘积为 $-1$。当 $f'(x_0)\neq0$ 时：

$$\boxed{y-y_0=-\frac{1}{f'(x_0)}\,(x-x_0)}$$

若 $f'(x_0)=0$（切线水平），法线是铅垂线 $x=x_0$。

:::trap
"在点 $P$ 处的切线"与"过点 $P$ 的切线"不同。前者 $P$ 就是切点，直接代公式；后者 $P$ 可能在曲线外，要设切点 $(x_1,f(x_1))$ 再联立。期中考的都是前者，但**读题时确认"在"还是"过"**。
:::

:::practice
切线题的最后一步是"整理成一般式"。直接写 $y-y_0=k(x-x_0)$ 也算对，但整理过更接近标准答案，也便于检查符号。**验算方法：把切点代回你写的方程，必须成立。**
:::

## 速查

### 切线 / 法线

| 对象 | 公式 | 备注 |
| --- | --- | --- |
| 切线 | $y-y_0=f'(x_0)(x-x_0)$ | $P(x_0,y_0)$ 为切点 |
| 法线 | $y-y_0=-\dfrac{1}{f'(x_0)}(x-x_0)$ | 需 $f'(x_0)\neq0$ |
| 法线（$f'(x_0)=0$） | $x=x_0$ | 铅垂线 |
| 切线（$f'(x_0)=\pm\infty$） | $x=x_0$ | 铅垂切线，**仅当两侧导数都趋于 $\pm\infty$**（如 $x^{2/3}$ 在 $0$） |

### 常用微分

| 函数 | 微分 |
| --- | --- |
| $x^{n}$ | $nx^{n-1}dx$ |
| $\sin x$ | $\cos x\,dx$ |
| $\cos x$ | $-\sin x\,dx$ |
| $e^{x}$ | $e^{x}dx$ |
| $\ln x$ | $\dfrac{dx}{x}$ |
| $\arctan x$ | $\dfrac{dx}{1+x^{2}}$ |

### 微分与导数的区别（选择题可能问）

| | 导数 $f'(x)$ | 微分 $dy$ |
| --- | --- | --- |
| 是什么 | 一个数（或函数） | 一个量，$f'(x)dx$ |
| 单位 | 因变量/自变量 | 随 $dx$ 变化 |
| 关系 | $dy=f'(x)dx$ | $\dfrac{dy}{dx}=f'(x)$ |

## 题

:::problem id=2.8-01 level=易 source="本站自编"
求曲线 $y=x\ln x$ 在 $x=1$ 处的切线斜率。

:::ans
$$y'=\ln x+x\cdot\frac1x=\ln x+1 .$$

代入 $x=1$：$y'(1)=0+1=1$。

**复算**：`2.8-01` 的 verify 用数值导数复算，得 $1$。
:::
:::

:::problem id=2.8-02 level=中 source="2024–2025 期中 · 解答题 5 同类"
求曲线 $y=x\ln x$ 在 $x=1$ 处的切线方程与法线方程。

:::ans
**切线**：

切点：$y(1)=1\cdot\ln1=0$，即 $(1,0)$。

斜率：$y'=\ln x+1$，故 $k=y'(1)=1$。

切线：

$$y-0=1\cdot(x-1)\quad\Longrightarrow\quad y=x-1 .$$

**法线**：斜率为 $-\dfrac{1}{k}=-1$，

$$y-0=-1\cdot(x-1)\quad\Longrightarrow\quad y=-x+1 .$$

**复算**：`2.8-02` 的 verify 检验切线截距 $=y_0-kx_0=0-1\cdot1=-1$，与 $y=x-1$ 一致。
:::
:::

:::problem id=2.8-03 level=难 source="本站自编"
设 $f(x)=\begin{cases}x^{2}\sin\dfrac1x, & x\neq0\\ 0, & x=0\end{cases}$，判断 $f$ 在 $x=0$ 处是否连续、是否可导。

:::ans
**连续性**：

$$\left\lvert x^{2}\sin\frac1x\right\rvert\le x^{2}\ \longrightarrow\ 0 .$$

由夹逼准则 $\lim\limits_{x\to0}f(x)=0=f(0)$，故**连续**。

**可导性**：用定义，

$$f'(0)=\lim_{x\to0}\frac{f(x)-f(0)}{x-0}=\lim_{x\to0}\frac{x^{2}\sin\frac1x}{x}=\lim_{x\to0}x\sin\frac1x .$$

因为 $x\to0$ 是无穷小、$\sin\dfrac1x$ 是有界量，故

$$\lim_{x\to0}x\sin\frac1x=0 ,$$

所以 $f'(0)=0$，**可导**。

:::key
"无穷小 × 有界量 = 无穷小"这一句要**明确写出来**。2025–2026 解答题第 5 题的得分点就在这里：光算对极限不够，要说明为什么是 0。
:::
:::
:::

:::key
这一节两处得分：单选一道（切线方程，3 分）＋解答题第 5 题可能考可导性讨论（8 分）。**切线四个动作 + 法线斜率取负倒数 + 左右导数定义**，本章最后 11 分。
