## 锚点结果

方程 $x^{2}+xy+y^{2}=3$ 确定的隐函数 $y=y(x)$：

$$y'=-\frac{2x+y}{x+2y}$$

在点 $(1,1)$ 处：$y'=-\dfrac{2+1}{1+2}=-1$。

这一节四年里考了**四次解答题**（8 分），是第二章最稳定的得分点。答案形式简单，过程也机械。

## 机制

### 什么是隐函数

显函数写成 $y=f(x)$，右边只有 $x$。隐函数是用一个方程 $F(x,y)=0$ 把 $x$ 与 $y$ 的关系"藏着"——比如 $x^{2}+y^{2}=1$。

求导不需要解出 $y$。办法是：**把 $y$ 看成 $x$ 的函数，两边同时对 $x$ 求导。**

### 核心：把 $y$ 当函数，乘上 $y'$

这是全节唯一要理解的一点。对含 $y$ 的项求导时，链条是"先对 $y$ 求导，再乘 $y'$"：

| 式子 | 对 $x$ 求导的结果 | 为什么 |
| --- | --- | --- |
| $y$ | $y'$ | 定义 |
| $y^{2}$ | $2yy'$ | 链式：外层平方，内层 $y$ |
| $y^{3}$ | $3y^{2}y'$ | 同上 |
| $\sin y$ | $\cos y\cdot y'$ | 链式 |
| $e^{y}$ | $e^{y}y'$ | 链式 |
| $xy$ | $y+xy'$ | 乘积法则：$(x)'y+x(y)'$ |
| $x^{2}y$ | $2xy+x^{2}y'$ | 乘积法则 |
| $\ln y$ | $\dfrac{y'}{y}$ | 链式 |

:::trap
两个最高频的错：<br>① $y^2$ 的导数写成 $2y$（漏了 $y'$）；<br>② $xy$ 的导数写成 $y'$（用错了法则，应该是 $y+xy'$）。<br>记住：**只有 $x$ 的式子直接求导；含 $y$ 的一律乘 $y'$；$x$ 与 $y$ 相乘的用乘积法则。**
:::

### 三步模板

**第一步**：写"方程两边同时对 $x$ 求导得："（这句话本身有过程分）

**第二步**：逐项求导，把含 $y'$ 的项留在左边，其余移到右边

**第三步**：解出 $y'$，写成 $\dfrac{dy}{dx}=\cdots$ 或 $y'=\cdots$

写完还可以做一件事：**如果题目给了点，把坐标代进去得数值**；如果没给，表达式里**保留 $y$ 是允许的**（课本就是这么要求的）。

### 完整例子

$x^{2}+xy+y^{2}=3$，两边对 $x$ 求导：

$$2x+y+xy'+2yy'=0 .$$

把含 $y'$ 的项归到一边：

$$xy'+2yy'=-(2x+y),$$

提出 $y'$：

$$y'(x+2y)=-(2x+y),$$

所以

$$y'=-\frac{2x+y}{x+2y}.$$

在 $(1,1)$ 处：$y'=-\dfrac{3}{3}=-1$。

:::practice
题目若问"在点 $(1,1)$ 处的切线"，先算出 $y'=-1$，再按 2.8 的点斜式写 $y-1=-1(x-1)$，即 $y=-x+2$。隐函数求导和切线两节经常连在一起考。
:::

## 速查

### 常见项求导表

| 项 | 导数 |
| --- | --- |
| $y$ | $y'$ |
| $y^{n}$ | $ny^{n-1}y'$ |
| $xy$ | $y+xy'$ |
| $x^{2}y$ | $2xy+x^{2}y'$ |
| $\dfrac{y}{x}$ | $\dfrac{y'x-y}{x^{2}}$ |
| $\sin y$ | $\cos y\cdot y'$ |
| $\cos y$ | $-\sin y\cdot y'$ |
| $e^{y}$ | $e^{y}y'$ |
| $\ln y$ | $\dfrac{y'}{y}$ |
| $\arctan y$ | $\dfrac{y'}{1+y^{2}}$ |

### 三种问法与对应的收尾动作

| 题目问 | 收尾动作 |
| --- | --- |
| 求 $y'$ 的表达式 | 直接写出，含 $y$ 没关系 |
| 求在点 $(x_0,y_0)$ 处的 $y'$ | 把坐标代进表达式算数值 |
| 求切线方程 | 算出 $y'$ 后用点斜式，整理成一般式 |

## 题

:::problem id=2.5-01 level=中 source="2025–2026 期中 · 解答题 3 同类"
设 $y=y(x)$ 由方程 $x^{2}+xy+y^{2}=3$ 确定，求 $\dfrac{dy}{dx}$ 在点 $(1,1)$ 处的值。

:::ans
**解**：方程两边同时对 $x$ 求导得

$$2x+y+xy'+2yy'=0 .$$

整理：

$$y'(x+2y)=-(2x+y),$$

所以

$$\frac{dy}{dx}=-\frac{2x+y}{x+2y} .$$

代入 $x=1,y=1$：

$$\left.\frac{dy}{dx}\right|_{(1,1)}=-\frac{2+1}{1+2}=-1 .$$

**复算**：`2.5-01` 的 verify 把方程解成显式分支 $y=\dfrac{-x+\sqrt{12-3x^{2}}}{2}$，再数值求导，得 $-1$。
:::
:::

:::problem id=2.5-02 level=中 source="2024–2025 期中 · 解答题 3 同类"
设 $y=y(x)$ 由 $e^{y}+xy=2$ 确定，求 $y'$。

:::ans
两边对 $x$ 求导：

$$e^{y}y'+y+xy'=0 .$$

整理：

$$y'\left(e^{y}+x\right)=-y,$$

所以

$$y'=-\frac{y}{e^{y}+x} .$$

**验算**：取 $x=0$，由原方程 $e^{y}=2$ 得 $y=\ln 2$，代入得

$$y'(0)=-\frac{\ln 2}{2+0}=-\frac{\ln 2}{2}\approx-0.3466 .$$

用数值方法在 $x=0$ 附近解出 $y$ 再求差商，结果一致。

:::trap
$xy$ 的导数是 $y+xy'$，不是 $y'$ 也不是 $xy'$。这是这道题唯一的坑；漏掉 $y$ 会得到 $y'=-\dfrac{0}{e^y+x}=0$，明显不合理。
:::
:::
:::

:::problem id=2.5-03 level=难 source="本站自编"
设 $y=y(x)$ 由 $\ln y+x y=1$ 确定，求 $y'(0)$。

:::ans
先求 $x=0$ 时 $y$ 的值：代回原方程，$\ln y+0=1$，得 $y=e$。

两边对 $x$ 求导：

$$\frac{y'}{y}+y+xy'=0 .$$

整理：

$$y'\left(\frac1y+x\right)=-y\ \Longrightarrow\ y'=-\frac{y}{\frac1y+x}=-\frac{y^{2}}{1+xy} .$$

代入 $x=0,y=e$：

$$y'(0)=-\frac{e^{2}}{1+0}=-e^{2}\approx-7.389 .$$

:::key
**先求点的坐标，再求导**——题目只给 $x=0$ 时，必须先回原方程算出 $y(0)$。这一步很多人跳过，导致代入时缺 $y$ 的值。
:::
:::
:::

隐函数求导是解答题第 3 题，固定 8 分。**三步模板背下来 + 表格里那几行求导不出错**，这 8 分是整张卷子里第二稳的（第一稳是参数方程）。
