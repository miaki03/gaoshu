# 高数 A-1：一周把期中分捞回来，然后把课补上

这个站有两个用途，**别混着用**：

- **要考试了**：走「期中冲刺」——考点地图、公式卡、五个答题模板、真题。这是为了拿分，不是为了学懂。
- **考完之后**：走「极限与连续」「导数与微分」——按节学，每节 15–25 分钟，有锚点结果、机制、速查、题。

:::key
**如果你现在只有一周**：先看 [考点地图](/s/exam-map) 确认范围（就两章），然后照 [冲刺计划](/s/cram-plan) 的七天表走。别从第一节开始顺着读。
:::

## 这个站和其他资料的区别

我们学校的期中卷有个特点：**题型高度固定**。四年里，"间断点分类"考了四次，"零点定理"考了四次，"隐函数求导"作为解答题考了四次。这意味着两件事：

1. 你不需要学完整本教材才能及格——**七八个模板就够到 80 分**；
2. 但想上 90，得真的会推导，因为最后那 10% 是区分题。

所以这个站把内容分了两层：冲刺层给模板与真题，学习层给推导与练习。**先用冲刺层救急，考完再回学习层补根基。**

## 最快的用法

1. 按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 搜索任何考点，比如「间断点」「隐函数」「切线」；
2. 每节底部有**掌握度按钮**（未看 / 看过 / 会做 / 熟练），标过就记在这台设备的浏览器里，左侧导航会打勾；
3. 做错的题点卡片上的「记错」，收进[错题本](/errors)，考前只看它；
4. [我的进度](/progress)页能看到 15 节里哪几节已经"会做"。
