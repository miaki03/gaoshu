## 一句话说清怎么安排

按大纲的权重：第三章 33%、第五章 30%、第四章 15%，第一章和第二章合计 15%。

**顺序是 3 → 4 → 5**，不是 1 → 5：

- 第三章的"极值、单调性、凹凸"是第五章面积体积题的工具；
- 第四章的"凑微分"是第五章算定积分的前提。

一二章不重学，只做抽查——你在期中前已经把这两章的正文过了一遍。

## 每节怎么用

每节 15–25 分钟，固定四件套：**锚点结果 → 机制 → 速查 → 题**。看完一节立刻做本校《检测题》对应小节（编号直接对应教材小节，3-1 就是 3.1 节），这是工作区里唯一按小节排的本校材料。

:::practice
每节底部有掌握度按钮（未看 / 看过 / 会做 / 熟练），标过就记在这台设备的浏览器里。做错的题点卡片上的「记错」，收进[错题本](/errors)。期末前只看错题本。
:::
