## 三种页面，三种读法

| 页面 | 长什么样 | 怎么读 |
| --- | --- | --- |
| **冲刺页**（考点地图、公式卡、题型手册） | 大量表格 | 不用通读。**先搜索你要的那个表**，背它 |
| **章节正文**（1.1、2.3 这些） | 有"锚点结果"开头 | 按四件套顺序读，读完立刻做题 |
| **真题页** | 每题一张卡片，答案折叠 | 先做后看，把错的记进错题本 |

## 每节的固定结构（四件套）

所有章节正文都是同一个骨架，**顺序不变**：

| 件 | 作用 | 怎么用 |
| --- | --- | --- |
| **锚点结果** | 一上来就给一个具体的、可核对的结果 | 先自己算，算不出来说明这节要学 |
| **机制** | 为什么是这样，推导不跳步 | 慢读，这是"会"和"背"的分界 |
| **速查** | 本节用到的表，就地给 | 不背，做题时回来查 |
| **题** | 1–3 道，带折叠答案 | 必做，做完点"记错"或"掌握度" |

:::key
判断自己"学过了"还是"会了"，标准只有一个：**合上页面，能不能把锚点结果算出来。** 看着眼熟不算。
:::

## 进度怎么记

每节页面底部有一条横栏：

```text
这节掌握到什么程度？  [未看] [看过] [会做] [熟练]
```

- **未看**：还没碰
- **看过**：读完了，但做题还要看答案
- **会做**：合上页面能做对
- **熟练**：能默写模板，考场不慌

标记后会立刻生效：左侧导航会出现对勾，[我的进度](/progress)页会统计。

:::conv
数据只存在**这台设备的浏览器**里（`localStorage`），不上传、不需要登录。换设备或换浏览器会看不到——用进度页的「导出 / 导入」搬过去。
:::

## 错题本怎么用

真题卡片和练习题卡片右上角有「记错」按钮。点一下：

- 题目正文会被摘出来存进[错题本](/errors)
- 按钮变成红色，表示已收录
- 再点一次取消

**考前一晚只看错题本。** 这是投入产出比最高的复习方式：改一个错，涨 3 分；学一个新考点，可能是 0 分。

## 搜索

按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（Mac 是 <kbd>Cmd</kbd>+<kbd>K</kbd>），或点顶栏的放大镜。

能搜到：节标题、摘要、正文全文。中文直接搜关键词就行，比如：

- `间断点` → 四分类表
- `等价无穷小` → 九组公式
- `切线` → 点斜式与例题
- `隐函数` → 三步模板

:::practice
搜索比翻导航快得多。**别在导航里找**，导航是用来"顺着学"的，搜索是用来"查东西"的。
:::

## 页面上的标记

正文里会出现几种带颜色的小块，含义固定：

| 标记 | 含义 | 怎么处理 |
| --- | --- | --- |
| **易错** | 别人踩过的坑，考场上会重复出现 | 一定读完，这是最省分的部分 |
| **重点** | 这节的核心结论，必须记住 | 抄到公式卡上 |
| **约定** | 习惯做法，不是硬规定 | 知道就行 |
| **实践** | 操作层面的建议 | 照着做 |
| **为什么** | 这条结论的来源，防止背错 | 时间是够就读，不够可跳 |
| **练** | 题目卡片，右上角可以点「记错」 | 必做 |
| **答** | 折叠的解答，点一下展开 | 先自己做，再展开 |
| **真题** | 出自某年的真题 | 重点做 |

## 每道题的编号

题号形如 `1.5-02`，意思是**第 1 章第 5 节第 2 题**。真题的编号形如 `2025-S3`，意思是 2025 年解答题第 3 题。

编号有两个用处：

1. 错题本里靠编号找回原题；
2. 站内所有题的答案都由脚本复算过（见[关于与来源](/about)），编号就是索引。

## 学习节奏建议

| 你有多少时间 | 怎么走 |
| --- | --- |
| 7 天 | 照[冲刺计划](/s/cram-plan)的七天表 |
| 48 小时 | 公式卡 → 五个模板 → 一套真题 → 补错 |
| 3 小时 | 公式卡 → 错题本 → 题型手册，然后停手 |
| 考完以后 | 从 [1.1](/s/1-1-functions) 顺着学，一天 2–3 节 |

:::trap
最常见的错误是"把冲刺层当学习层用"：只看公式卡和模板，不理解机制。这样能及格，但遇到换外壳的题会崩，而且期末要从头再来。**期中考完一定回来补学习层。**
:::
