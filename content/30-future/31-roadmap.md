## 先划边界：哪些是事实，哪些我不知道

这一页只写有原件依据的东西。**不确定的就不猜**——猜错的重点比不写更糟。

### 有原件依据的（可核对）

| 事实 | 数值 | 出处 |
| --- | --- | --- |
| 期末范围 | 第一至第五章全部知识点 | 《考核大纲》第二节 |
| 各章权重 | 第一章 9%、第二章 6%、**第三章 33%**、第四章 15%、**第五章 30%**、综合素质 7% | 同上 |
| 章内顺序 | §1.1 → §1.7 → §2.1 → §2.5 → §3.1 → §3.5 → §4.1 → §4.3 → §5.1 → §5.5 | 《教学进度》36 次课 |
| 题型措辞 | "填空题、选择题、计算题、证明题、应用题等" | 《考核大纲》第三节 |
| 本校练习 | 《检测题》按小节编排，覆盖到 5-5，对应期末五章的每一节 | `assets/files/drills-2026.doc` |

### 我不知道的（所以本站不写）

| 未知 | 为什么不知道 | 本站怎么处理 |
| --- | --- | --- |
| 期末具体日期 | 《考核大纲》只写了"第 12 周"是期中，期末日期没有出现在任何文件里 | 页面不写日期，倒计时显示"日期未定" |
| 期末卷型（几道题、每题几分） | 大纲只给了题型名称，没有题量与分值分配 | **不写"填空 10×3"这类结构**，按知识点组织 |
| 往年期末真题 | 工作区里只有四次**期中**卷，没有期末卷 | 不出"期末真题解析"；练习用本校《检测题》+ 自编可复算题 |
| 老师划的重点 | 没有这类材料 | 不写"必考""压轴"这类无法核实的断言 |

:::trap
如果以后看到任何资料声称"期末必考某某题型""期末是 X 题"，先问它有没有原件。**大纲里没有的信息，任何推断都是猜。** 这一页的权重表是抄的，卷型不是——因为前者有原文，后者没有。
:::

## 权重表：时间该往哪放

按大纲给的百分比，期末复习的时间分配应该大致照这个走：

| 章 | 期末占比 | 本站对应 | 一句话判断 |
| --- | --- | --- | --- |
| 第三章 微分中值定理与导数应用 | **33%** | 3.1–3.5 | 单项最大，且第四、五章都建在它上面 |
| 第五章 定积分及其应用 | **30%** | 5.1–5.5 | 第二大块，计算与几何应用为主 |
| 第四章 不定积分 | 15% | 4.1–4.3 | 是第五章的前置，必须练到熟 |
| 第一章 函数与极限 | 9% | 1.1–1.7 | 期中已经打过底，抽查即可 |
| 第二章 导数与微分 | 6% | 2.1–2.8 | 同上，抽查即可 |
| 综合素质 | 7% | — | 形式未说明 |

:::key
**为什么先第三章**：它是 33% 的单项最大，而且"极值/单调性/凹凸"这些工具会被第五章的面积体积题反复用到；第四章的"凑微分"又是第五章算定积分的前提。所以顺序是 **3 → 4 → 5**，而不是按章号顺着读。
:::

## 每章要练成的能力

不写"理解 X"，只写"给定 Y 能做出 Z"。这三条是验收标准：做不出来就回去补那一节。

:::conv
**第三章**：① 写出罗尔/拉格朗日的条件与结论并用它证明简单命题；② 用洛必达处理 0/0 与 ∞/∞；③ 求单调区间、极值、凹凸区间、拐点、三类渐近线，并能画出草图。

**第四章**：① 写出基本积分表并说明原函数与不定积分的关系；② 用凑微分与换元求积分；③ 用分部积分处理乘积型。

**第五章**：① 用牛顿-莱布尼茨算定积分；② 求变限积分函数的导数；③ 用定积分算面积与旋转体体积。
:::

## 本站期末部分的写法

每一节仍然按四件套来：

| 件 | 期末版的具体做法 |
| --- | --- |
| 锚点结果 | 一上来给一个具体、能自己核对的结果（算出一个数、写出一条定理的完整条件） |
| 机制 | 推导不跳步；定理要写全三个条件，并说明每个条件去掉会怎样 |
| 速查 | 本章用到的公式就地给（积分表、泰勒展开、判别法），不放附录 |
| 题 | 1–3 道，答案要么能被脚本复算，要么给出可逐行核对的推导 |

:::conv
期末这五章比期中的两章更依赖"算得准"。所以本站的写法是：**每道数值题的答案都登记进题库并复算**（`npm run verify`），正文里的推导例题也逐步给中间结果——这样你算错了能知道错在哪一步，而不是只知道自己错了。
:::
