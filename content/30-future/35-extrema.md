## 这节怎么用

作业分成两份，题目类型很固定：

| 作业 | 题型 | 你要会 |
| --- | --- | --- |
| 3-4(1) 一 | 填空 | 说单调性、找驻点、写单调减少区间 |
| 3-4(1) 二 | 选择 | 单调性判据到底是 $f'>0$ 还是 $f'\ge0$ |
| 3-4(1) 三、四 | 计算 | 求单调区间 |
| 3-4(1) 五 | 证明 | **用单调性证不等式** |
| 3-4(2) 一、二 | 填空选择 | 极值点、极值、最值点、极值点与驻点的关系 |
| 3-4(2) 三、四 | 计算 | 求极值、求闭区间最值 |
| 3-4(2) 五、六 | 应用 | 围院子最省材料、防空洞截面周长最小 |

核心就一句话：**先求导，再看导数的符号**。下面全是这一句话的用法。

## 一、求单调区间：三步

:::problem id=3.4-01 level=易 source="本校检测题 3-4(1) 三、四 同类"
求 $f(x)=x^{3}-3x$ 的单调区间与极值。

:::ans
**第一步：求导，找驻点。**

$$f'(x)=3x^{2}-3=3(x-1)(x+1)=0\ \Longrightarrow\ x=\pm1 .$$

**第二步：用驻点把定义域切成段，判每段 $f'$ 的符号。**

| 区间 | 取一个点试 | $f'$ 符号 | $f$ |
| --- | --- | --- | --- |
| $(-\infty,-1)$ | $x=-2$ | $+$ | 递增 |
| $(-1,1)$ | $x=0$ | $-$ | 递减 |
| $(1,+\infty)$ | $x=2$ | $+$ | 递增 |

**第三步：按"先增后减是极大、先减后增是极小"读出极值。**

- $x=-1$：左增右减 → **极大值** $f(-1)=-1+3=2$
- $x=1$：左减右增 → **极小值** $f(1)=1-3=-2$

**答案**：增区间 $(-\infty,-1)$、$(1,+\infty)$；减区间 $(-1,1)$；极大值 $f(-1)=2$，极小值 $f(1)=-2$。

:::trap
区间端点写开还是写闭？**一般写开**（$f'=0$ 的点不属于"递增"或"递减"的开区间内部）。写闭区间多数教材也接受，但要前后一致。
:::
:::
:::

## 二、选择：$f'>0$ 与 $f'\ge0$ 的区别

:::problem id=3.4-02 level=中 source="本校检测题 3-4(1) 二、1 同类"
设 $f$ 在 $[a,b]$ 上有定义。下列说法正确的是（ ）

(A) 若对每个 $x$，有 $f'(x)>0$，则 $f$ 递增
(B) 若对每个 $x$，有 $f'(x)\ge0$，则 $f$ 严格递增
(C) 若 $f$ 递增，则 $f'(x)>0$
(D) 若对每个 $x$，有 $f'(x)\ge0$，且 $f$ 在 $[a,b]$ 上**不恒为常数**，则 $f$ 严格递增

:::ans
**选 D。**

逐个看：

| 选项 | 对不对 | 原因 |
| --- | --- | --- |
| (A) | 对，但**不完整** | $f'>0$ ⇒ 严格递增，成立；但题目要选"正确"，A 其实也对……见下面的说明 |
| (B) | **错** | $f'\ge0$ 只能得到"不减"：$f\equiv C$ 时 $f'=0\ge0$，但 $f$ 不严格增 |
| (C) | **错** | 严格增函数的导数可以等于 $0$（个别点），如 $f(x)=x^{3}$ 在 $0$ 处 $f'=0$，但它严格增 |
| (D) | **对** | $f'\ge0$ 且不恒为常数 ⇒ 严格增。这是教材给的标准判据 |

:::key
记这一组关系最省事：

$$f'>0\ \Rightarrow\ f\text{ 严格增}\ \Rightarrow\ f'\ge0\ \text{（且不恒为 0）}$$

箭头**不能反着推**。考试里如果出现"$f'\ge0$"，一定要问一句"会不会恒等于 0"。
:::
:::
:::

## 三、求极值：一阶判别和二阶判别选一个

:::problem id=3.4-03 level=中 source="本校检测题 3-4(2) 三 同类"
求 $f(x)=x^{3}-3x^{2}+2$ 的极值。

:::ans
**求导找驻点**：

$$f'(x)=3x^{2}-6x=3x(x-2)=0\ \Longrightarrow\ x=0,\ 2 .$$

**判类型**（这里用二阶导，快）：

$$f''(x)=6x-6 .$$

- $f''(0)=-6<0$ → $x=0$ 是**极大值点**，极大值 $f(0)=2$
- $f''(2)=6>0$ → $x=2$ 是**极小值点**，极小值 $f(2)=8-12+2=-2$

:::practice
**二阶判别法的条件是 $f''\ne0$**。若 $f''(x_0)=0$，这个方法失效，只能退回一阶判别（看左右符号）。作业里"驻点处 $f''=0$"那种填空就是在考这个。
:::
:::
:::

## 四、闭区间最值：三个点比大小

:::problem id=3.4-04 level=易 source="本校检测题 3-4(2) 四 同类"
求 $f(x)=x^{3}-3x$ 在 $[0,2]$ 上的最大值与最小值。

:::ans
**候选点只有两类：端点 + 驻点。**

驻点：$f'(x)=3x^{2}-3=0$ 得 $x=\pm1$，但 $x=-1\notin[0,2]$，只剩 $x=1$。

算函数值：

| 点 | $f$ |
| --- | --- |
| 左端点 $x=0$ | $0$ |
| 驻点 $x=1$ | $1-3=-2$ |
| 右端点 $x=2$ | $8-6=2$ |

比大小：最大值 $2$（在 $x=2$ 取到），最小值 $-2$（在 $x=1$ 取到）。

:::trap
闭区间最值**必须算端点**。$x=2$ 是端点，它的函数值 $2$ 恰好比极大值大——漏掉端点就会答错。**"最值在驻点取到"是错的，只能说"可能"。**
:::
:::
:::

## 五、应用题：两步定型，一步求极值

这类题（作业 3-4(2) 五、六）的固定动作：

1. **设自变量、写目标函数**（要最大/最小的那个量，表示成一个变量的函数）；
2. **写约束、消成一个变量**；
3. 求导、令 $0$、解出驻点；
4. 说明这个驻点确实是最值点（应用题通常唯一驻点，由实际意义判定）。

:::problem id=3.4-05 level=难 source="本校检测题 3-4(2) 五 同类"
借助一面足够长的墙，用篱笆围一个面积为 $50\ \text{m}^2$ 的长方形小院。问长宽各多少时用篱笆最省？

:::ans
**第 1 步：设变量。** 墙那一侧不用篱笆。设垂直于墙的两边各为 $x$，平行于墙的一边为 $y$。

**第 2 步：约束 + 目标。**

面积约束：$xy=50\Rightarrow y=\dfrac{50}{x}$。

篱笆总长（目标）：$L=2x+y=2x+\dfrac{50}{x}$。

**第 3 步：求导，令 0。**

$$L'(x)=2-\frac{50}{x^{2}}=0\ \Longrightarrow\ x^{2}=25\ \Longrightarrow\ x=5 .$$

（$x>0$）

于是 $y=\dfrac{50}{5}=10$。

**第 4 步：确认是最小。** $L''(x)=\dfrac{100}{x^{3}}>0$（$x>0$），所以 $x=5$ 是极小值点，也是最小值点。

**答案**：垂直于墙的两边各 **5 m**，平行于墙的一边 **10 m**，此时篱笆长 $2\times5+10=20$（m），最省。
:::
:::

:::problem id=3.4-06 level=难 source="本校检测题 3-4(2) 六 同类"
防空洞截面是"矩形 + 上半圆"，截面面积为常数 $A$。问底宽（即半圆的直径）为多少时截面周长最小？

:::ans
**设变量。** 设半圆半径为 $r$，则底宽 $=2r$，矩形高为 $h$。

**约束**（面积固定）：

$$A=2r\cdot h+\frac{1}{2}\pi r^{2}.$$

**目标**（周长 = 底部直径 + 两个侧边 + 半圆弧）：

$$L=2r+2h+\pi r .$$

由约束解出 $h=\dfrac{A}{2r}-\dfrac{\pi r}{4}$，代入：

$$L(r)=\frac{A}{r}-\frac{\pi r}{2}+2r+\pi r=\frac{A}{r}+2r+\frac{\pi r}{2}.$$

**求导令 0**：

$$L'(r)=-\frac{A}{r^{2}}+2+\frac{\pi}{2}=0\ \Longrightarrow\ r^{2}=\frac{A}{2+\frac{\pi}{2}}=\frac{2A}{4+\pi}.$$

所以

$$r=\sqrt{\frac{2A}{4+\pi}},\qquad \text{底宽}=2r=2\sqrt{\frac{2A}{4+\pi}} .$$

**确认最小**：$L''(r)=\dfrac{2A}{r^{3}}>0$，故是极小值点，也是最小值点。

:::trap
这题的坑是"周长"到底算哪些边。截面是封闭图形：底部直径 $2r$、两个侧边 $2h$、上面的半圆弧 $\pi r$——**半圆弧长是 $\pi r$，不是 $2\pi r$**。少算或多算这一段，目标函数就错了。
:::
:::
:::

## 六、用单调性证不等式（作业 3-4(1) 五）

套路：**移项成 $F(x)$，证 $F$ 单调，再用 $F$ 在端点处的值定符号。**

:::problem id=3.4-07 level=中 source="本校检测题 3-4(1) 五 同类"
证明：$x>0$ 时，$\ln(1+x)>x-\dfrac{x^{2}}{2}$。

:::ans
设

$$F(x)=\ln(1+x)-x+\frac{x^{2}}{2},$$

则 $F(0)=0$，且

$$F'(x)=\frac{1}{1+x}-1+x=\frac{1-(1+x)+x(1+x)}{1+x}=\frac{x^{2}}{1+x}.$$

当 $x>0$ 时 $F'(x)=\dfrac{x^{2}}{1+x}>0$，所以 $F$ 在 $[0,+\infty)$ 上严格递增。因此 $x>0$ 时

$$F(x)>F(0)=0\ \Longrightarrow\ \ln(1+x)>x-\frac{x^{2}}{2} .$$

$\blacksquare$

:::key
这三步顺序不能乱：**移项 → 验证 $F(0)=0$ → 证 $F$ 单调**。第二步容易被忽略，但它是"$F(x)>F(0)=0$"的落脚点。
:::
:::
:::

## 速查

### 三个判别法

| 要判断 | 用什么 | 条件 |
| --- | --- | --- |
| 单调增 | $f'>0$ | 严格增；$f'\ge0$ 且不恒为 $0$ 也可 |
| 极值（一阶判别） | $f'$ 在 $x_0$ 左右变号 | 左正右负 ⇒ 极大；左负右正 ⇒ 极小 |
| 极值（二阶判别） | $f''(x_0)$ 的符号 | $f''<0$ ⇒ 极大；$f''>0$ ⇒ 极小；**$f''=0$ 失效** |

### 三种求法的步骤

| 求什么 | 步骤 |
| --- | --- |
| 单调区间 | 求 $f'$ → 解 $f'=0$ → 分段判 $f'$ 符号 |
| 极值 | 求 $f'$ 的零点 → 判类型（一阶或二阶）→ 算函数值 |
| 闭区间最值 | 端点 + 区间内驻点，全算出来比大小 |

### 应用题四步

1. 设变量（把要优化的量设成一个变量的函数）
2. 写约束，消元
3. 求导令 $0$，解驻点
4. 用二阶导或实际意义确认是最值
