## 一、原函数与不定积分：只有两条式子

定义一句话：$F'(x)=f(x)$，就称 $F$ 是 $f$ 的一个**原函数**；$f$ 的全部原函数写成 $\int f(x)\,dx=F(x)+C$，叫 $f$ 的**不定积分**。

所以不定积分的结果**必须带 $C$**，原函数则是其中一个具体函数。这两件事在填空里是两种问法。

两条恒等式把"求导"和"积分"接起来：

$$\left(\int f(x)\,dx\right)'=f(x),\qquad \int f'(x)\,dx=f(x)+C .$$

第一条不带常数，第二条带。原因是第一条是"先积再导"，积分加的那个 $C$ 一求导就没了。

:::trap
答案漏写 $+C$ 是不定积分最常丢的分。判卷只看两处：结果对不对，$C$ 有没有。**每一步积分之后立刻写 $+C$**，不要留到最后补。
:::

:::problem id=4.1-01 level=易 source="本校检测题 4-1 一、1 同类"
设 $f(x)$ 的一个原函数是 $\sin x$。写出 $f(x)$、$f'(x)$，以及 $\int f'(x)\,dx$。

:::ans
**求 $f$**：原函数的导数就是被积函数，
$$f(x)=(\sin x)'=\cos x .$$

**求 $f'$**：再导一次，
$$f'(x)=(\cos x)'=-\sin x .$$

**求 $\int f'$**：用第二条恒等式，
$$\int f'(x)\,dx=f(x)+C=\cos x+C .$$

注意最后一步不是 $-\sin x+C$。$\int f'$ 回到的是 $f$，不是 $f'$——这是这道题唯一的坑。

:::key
三问三答，各自落在一条式子上：

| 问 | 用哪条 |
| --- | --- |
| 已知原函数，求 $f$ | $f=F'$（原函数的导数） |
| 求 $f'$ | 再导一次 |
| 求 $\int f'$ | $\int f'=f+C$ |
:::
:::
:::

## 二、基本积分表：查表，不算

积分表就是求导表的反写。**背的方式是反着背**：看到 $\int\cos x\,dx$，脑子里先出 $(\sin x)'=\cos x$，答案就是 $\sin x$。

:::problem id=4.1-02 level=易 source="本校检测题 4-1 三、1 同类"
计算 $\displaystyle\int\left(x^{5}+\frac{1}{x^{2}}+\sqrt{x}\right)dx$。

:::ans
三项分别查表，再用"和的积分等于积分的和"：

$$\int x^{5}dx=\frac{x^{6}}{6},\qquad \int\frac{dx}{x^{2}}=\int x^{-2}dx=\frac{x^{-1}}{-1}=-\frac1x,\qquad \int\sqrt{x}\,dx=\int x^{1/2}dx=\frac{x^{3/2}}{3/2}=\frac23x^{3/2}.$$

合起来：
$$\int\left(x^{5}+\frac{1}{x^{2}}+\sqrt{x}\right)dx=\frac{x^{6}}{6}-\frac1x+\frac23x^{3/2}+C .$$

**验算方法**（自己检查答案唯一可靠的办法）：把结果求导，看是否回到被积函数。$\left(\frac{x^6}{6}\right)'=x^5$，$\left(-\frac1x\right)'=\frac{1}{x^{2}}$，$\left(\frac23x^{3/2}\right)'=x^{1/2}$，对上了。

:::trap
$\dfrac{1}{x^{2}}$ 要**先写成 $x^{-2}$** 再用幂公式，指数 $-2\neq-1$，所以可以用。只有 $\dfrac1x$（指数正好 $-1$）不能用幂公式，它的原函数是 $\ln\lvert x\rvert$。
:::
:::
:::

:::problem id=4.1-03 level=中 source="本校检测题 4-1 二、1 同类"
已知 $f(x)$ 的一个原函数是 $\ln x$（$x>0$）。求 $f(x)$ 与 $\int f(x)\,dx$。

:::ans
**求 $f$**：原函数求导，
$$f(x)=(\ln x)'=\frac1x .$$

**求 $\int f$**：题目已经把答案给了一半。既然 $\ln x$ 是 $f$ 的一个原函数，那么全部原函数就是
$$\int f(x)\,dx=\ln x+C .$$

这道题考的是分清两个方向：

| 已知 | 求 | 做法 |
| --- | --- | --- |
| 原函数 $F$ | $f$ | 求导：$f=F'$ |
| 原函数 $F$ | $\int f$ | 直接写 $F+C$，不用算 |

:::practice
选择题里常见的干扰项是 $\ln x$（少 $C$）、$\ln x+1$（只给了一个原函数，不是全部原函数）、$\dfrac1x+C$（把 $f$ 当成了 $\int f$）。**看到"不定积分"，先找有没有 $C$。**
:::
:::
:::

## 三、先变形，再查表

被积函数长得不像表里的任何一条时，先做代数变形：拆项、化简、把分母拆开。变形成表里的形式之后再查。

:::problem id=4.1-04 level=中 source="本校检测题 4-1 三、2 同类"
计算 $\displaystyle\int\left(2^{x}+\frac{1}{1+x^{2}}+\sin x\right)dx$。

:::ans
三项都在表里，直接查：

$$\int 2^{x}dx=\frac{2^{x}}{\ln 2},\qquad \int\frac{dx}{1+x^{2}}=\arctan x,\qquad \int\sin x\,dx=-\cos x .$$

所以
$$\int\left(2^{x}+\frac{1}{1+x^{2}}+\sin x\right)dx=\frac{2^{x}}{\ln 2}+\arctan x-\cos x+C .$$

两个容易写错的地方：指数函数的原函数要**除以 $\ln a$**（$a=e$ 时 $\ln e=1$，所以 $e^x$ 不用除）；$\sin$ 的原函数是**负** $\cos$，符号别丢。

:::key
基本表按"求导公式"记，最容易错的是这四个符号/系数：

| 积分 | 结果 | 易错点 |
| --- | --- | --- |
| $\int a^{x}dx$ | $\dfrac{a^{x}}{\ln a}+C$ | 漏掉 $\ln a$ |
| $\int\sin x\,dx$ | $-\cos x+C$ | 漏负号 |
| $\int\cos x\,dx$ | $\sin x+C$ | — |
| $\int\dfrac{dx}{x}$ | $\ln\lvert x\rvert+C$ | 写成 $\ln x$ 在 $x<0$ 时错 |
:::
:::
:::

## 四、应用题：斜率是导数，过点是定常数

这类题的固定两步：**积分得到一族曲线，再代点定出 $C$**。第一步出来的一定带 $C$，所以答案不是一条曲线，是一族平行曲线；第二步才挑出其中一条。

:::problem id=4.1-05 level=中 source="本校检测题 4-1 四 同类"
一条曲线 $y=f(x)$ 过点 $(0,1)$，且在任意点 $x$ 处的切线斜率等于 $x^{3}$。求这条曲线的方程。

:::ans
**第一步：把"切线斜率"翻译成导数。** 切线斜率就是 $f'(x)$，所以
$$f'(x)=x^{3}.$$

**第二步：积分。**
$$f(x)=\int x^{3}dx=\frac{x^{4}}{4}+C .$$

**第三步：代点定 $C$。** 曲线过 $(0,1)$，即 $f(0)=1$：
$$f(0)=\frac{0^{4}}{4}+C=C=1 .$$

所以曲线方程是
$$y=\frac{x^{4}}{4}+1 .$$

**验算**：$y'=x^{3}$，且 $x=0$ 时 $y=1$。两条都满足。

:::trap
漏掉第三步是这类题的主要失分点。只写 $y=\frac{x^4}{4}+C$ 等于没答完——题目给的那个点就是用来把 $C$ 定成具体数字的。**题目里出现的每一个条件，都要在答案里用掉一次。**
:::
:::
:::

:::problem id=4.1-06 level=易 source="本校检测题 4-1 一、2 同类"
已知 $f'(x)=2x$，且 $f(1)=2$。求 $f(x)$。

:::ans
**第一步：积分。**
$$f(x)=\int 2x\,dx=x^{2}+C .$$

**第二步：代点定 $C$。**
$$f(1)=1^{2}+C=1+C=2\ \Longrightarrow\ C=1 .$$

所以 $f(x)=x^{2}+1$。

**验算**：$(x^{2}+1)'=2x$，且 $f(1)=1+1=2$。

:::key
这道题是上一题（4.1-05）的抽象版，两步完全一样：**积分得到 $f+C$ 这一族，代点挑出唯一那个。** 区别只在 4.1-05 的 $f'$ 来自"切线斜率"这句中文，这题的 $f'$ 直接给出。**看到"切线斜率""变化率""速度"，全部翻译成导数。**
:::
:::
:::

## 速查

### 基本积分表

| 被积函数 | 不定积分 | 备注 |
| --- | --- | --- |
| $x^{a}$ | $\dfrac{x^{a+1}}{a+1}+C$ | $a\neq-1$，$a$ 可为负、可为分数 |
| $\dfrac1x$ | $\ln\lvert x\rvert+C$ | $a=-1$ 的单独一条 |
| $e^{x}$ | $e^{x}+C$ | |
| $a^{x}$ | $\dfrac{a^{x}}{\ln a}+C$ | $a>0$，$a\neq1$ |
| $\sin x$ | $-\cos x+C$ | |
| $\cos x$ | $\sin x+C$ | |
| $\sec^{2}x=\dfrac{1}{\cos^{2}x}$ | $\tan x+C$ | |
| $\csc^{2}x=\dfrac{1}{\sin^{2}x}$ | $-\cot x+C$ | |
| $\sec x\tan x$ | $\sec x+C$ | |
| $\dfrac{1}{1+x^{2}}$ | $\arctan x+C$ | |
| $\dfrac{1}{\sqrt{1-x^{2}}}$ | $\arcsin x+C$ | $\lvert x\rvert<1$ |
| $\dfrac{1}{\sqrt{x^{2}+a^{2}}}$ | $\ln\left(x+\sqrt{x^{2}+a^{2}}\right)+C$ | 4-2(2) 里用三角代换能推出来 |

### 三条恒等式

| 式子 | 用途 |
| --- | --- |
| $\left(\int f(x)dx\right)'=f(x)$ | 已知不定积分，求被积函数 |
| $\int F'(x)dx=F(x)+C$ | 已知 $f'$，求 $f$（应用题第一步） |
| 结果的导数 = 被积函数 | **验算任何一道积分题**，这一步不花钱 |

### 四种题型的起手式

| 题目说 | 第一步做什么 |
| --- | --- |
| "默写积分表" | 反着背求导公式，一条一条对 |
| "哪个是 $f$ 的原函数" | 把每个选项求导，看哪个等于 $f$ |
| "计算 $\int\cdots dx$" | 先看能不能拆成表里的项；能拆就拆，不能拆再看下一节 |
| "切线斜率是…，求曲线" | 斜率写成 $f'$，积分，代点定 $C$ |
