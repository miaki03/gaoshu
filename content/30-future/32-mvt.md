## 这节怎么用

本校检测题 3-1 一共五类题。**先做，做不动再看讲解。** 每类题的讲解就在它下面。

| 题号 | 题型 | 考什么 |
| --- | --- | --- |
| 一、1–3 | 填空 | $f'\equiv0$ 型、拉格朗日定理的表述 |
| 二、1–4 | 选择 | 满不满足罗尔条件、$\xi$ 是多少、"有水平切线"的几何含义 |
| 三 | 解答 | **不求导数**，说明方程有几个实根、在哪 |
| 四、1–3 | 证明 | 证恒等式、证不等式、构造辅助函数证存在 $\xi$ |

## 一、选择：先判条件，再谈结论

:::problem id=3.1-01 level=易 source="本校检测题 3-1 二、1 同类"
下列函数中，在 $[-1,1]$ 上满足罗尔定理**所有**条件的是（ ）

(A) $f(x)=\lvert x\rvert$
(B) $f(x)=\dfrac1x$
(C) $f(x)=x^{2}$
(D) $f(x)=x^{3}$

:::ans
**选 C。**

逐项查三个条件——闭区间连续、开区间可导、两端相等：

| 选项 | 连续 | 可导 | 两端相等 | 结论 |
| --- | --- | --- | --- | --- |
| (A) $\lvert x\rvert$ | 是 | **否**（$x=0$ 处不可导） | 是 | 不满足 |
| (B) $\frac1x$ | **否**（$x=0$ 无定义） | 否 | 否 | 不满足 |
| (C) $x^{2}$ | 是 | 是 | $1=1$ | **满足** |
| (D) $x^{3}$ | 是 | 是 | $-1\neq1$ | 不满足 |

:::key
这类题不用算，就是**逐条查表**。查的顺序：先查**连续**（有分母、有 $\ln$、有根号的先看定义域），再查**可导**（有绝对值、有尖点的直接排除），最后查**两端相不相等**。前两条能刷掉大半。
:::
:::
:::

## 二、求 $\xi$：定理只保证存在，值要自己解

:::problem id=3.1-02 level=易 source="本校检测题 3-1 二、2 同类"
$f(x)=x^{3}-x$ 在 $[-1,1]$ 上满足罗尔定理，求定理中的 $\xi$。

:::ans
**第一步：查条件。** 多项式，连续可导；$f(-1)=0$，$f(1)=0$，两端相等。满足。

**第二步：解 $f'(\xi)=0$。**

$$f'(x)=3x^{2}-1=0\ \Longrightarrow\ x=\pm\frac{1}{\sqrt3}\approx\pm0.577 .$$

**第三步：筛掉区间外的。** 两个都在 $(-1,1)$ 里，所以

$$\xi=\pm\frac{1}{\sqrt3}\quad\text{（两个都算对）}$$

:::trap
罗尔定理只断言"存在"，不保证唯一。这题解出两个都在区间内，**题目问"求定理中的 $\xi$"时应该全写**；只写一个数学上不算错，但按"求所有满足条件的 $\xi$"这个理解会被扣分，写全更稳妥。
:::
:::
:::

## 三、填空：$f'\equiv0$ 就是常数

:::problem id=3.1-03 level=易 source="本校检测题 3-1 一、1 同类"
设 $f$ 在 $(a,b)$ 内可导，且恒有 $f'(x)=0$，又 $f(0)=-1$。求 $f(1)$。

:::ans
**答案：$-1$。**

理由一句话：**导数恒为零，函数就是常数。**

证明（一行）：设 $x$ 是区间内任一点。若 $x>0$，在 $[0,x]$ 上用拉格朗日；若 $x<0$，在 $[x,0]$ 上用（区间方向不影响结论）。两种情形都得到

$$f(x)-f(0)=f'(\xi)\,x=0\cdot x=0\ \Longrightarrow\ f(x)=f(0)=-1 .$$

所以 $f(1)=-1$。

:::key
这条叫**常值判据**，填空和选择的高频点。逆过来也常用：**两个函数导数相同，则它们只差一个常数。**
:::
:::
:::

## 四、解答：不求导数，数出实根个数

这是检测题 3-1 的第三大题，也是罗尔定理最漂亮的反用。

:::problem id=3.1-04 level=难 source="本校检测题 3-1 三 同类"
设 $f(x)=(x-1)(x-2)(x-3)$。**不求导**，说明方程 $f'(x)=0$ 有几个实根，并指出每个根所在的区间。

:::ans
**思路：$f$ 的根 → 用罗尔定理 → $f'$ 的根。**

$f$ 在 $[1,2]$ 上连续可导，且 $f(1)=f(2)=0$。由罗尔定理，存在 $\xi_1\in(1,2)$ 使 $f'(\xi_1)=0$。

同样，$f$ 在 $[2,3]$ 上连续可导，$f(2)=f(3)=0$。由罗尔定理，存在 $\xi_2\in(2,3)$ 使 $f'(\xi_2)=0$。

**结论**：$f'(x)=0$ 至少有两个实根，分别在 $(1,2)$ 与 $(2,3)$ 内。

**为什么正好两个**：$f$ 是三次多项式，$f'$ 是二次多项式，**最多**两个实根；已经找到两个，所以正好两个。

**事后验算**（这一步只用来检查，答题时不能这么写，因为题目要求"不求导"）：$f(x)=x^{3}-6x^{2}+11x-6$，$f'(x)=3x^{2}-12x+11$，解得 $x=2\pm\dfrac{1}{\sqrt3}\approx1.423,\ 2.577$，确实一个在 $(1,2)$、一个在 $(2,3)$。

:::practice
答题模板四句：① 指出 $f$ 在哪个区间连续可导；② 指出两端函数值为零；③ 引用罗尔定理得一个 $\xi$；④ 用"次数"说明不多不少。**第 ④ 步丢了会扣分**，因为只证明了"至少"。
:::
:::
:::

:::trap
这题的坑是"不求导"。你把 $f$ 展开再求导解方程，答案虽然对，但**题目要考的那个方法没答出来**，按评分标准很可能不给分。看到"不求导"三个字，就是让你用定理。
:::

## 五、证明：三类，各有固定起手式

### 5a 证恒等式（检测题 3-1 四、1）

套路：**设辅助函数 = 左边 − 右边，证导数为 0，再代一个点定常数。**

例：证明 $\arctan x+\arctan\dfrac1x=\dfrac{\pi}{2}$（$x>0$）。

设 $F(x)=\arctan x+\arctan\dfrac1x$，则

$$F'(x)=\frac{1}{1+x^{2}}+\frac{1}{1+\frac1{x^{2}}}\cdot\left(-\frac1{x^{2}}\right)=\frac{1}{1+x^{2}}-\frac{1}{x^{2}+1}=0 .$$

导数为 $0$ 只说明**在同一个区间上**是常数（这里区间是 $(0,+\infty)$）。取 $x=1$：$F(1)=\dfrac\pi4+\dfrac\pi4=\dfrac\pi2$，所以在 $x>0$ 时

$\arctan x+\arctan\frac1x=\frac{\pi}{2}\qquad(x>0).$

**$x<0$ 时结论不同**：同样的导数计算说明 $F$ 在 $(-\infty,0)$ 上也是常数，但取 $x=-1$ 得 $F(-1)=-\dfrac\pi4-\dfrac\pi4=-\dfrac{\pi}{2}$。完整写法要分两段——这正是这类题最容易丢分的地方：**导数恒为零只保证"分段常数"，每段要各自定常数。**

<!-- ex: 3.1-e1 -->

:::key
三步：**求导得 0 → 说明是常数 → 代一个点定这个常数**。第 3 步不能省，否则只知道"是常数"，不知道是几。
:::

### 5b 证不等式（检测题 3-1 四、2）

套路：**把不等号两边移成 $f(b)-f(a)$ 与 $b-a$，用拉格朗日，再放缩 $f'(\xi)$。**

例：$x>0$ 时证 $e^{x}>1+x$。

取 $f(t)=e^{t}$，在 $[0,x]$ 上用拉格朗日：

$$e^{x}-1=e^{\xi}\cdot x,\qquad \xi\in(0,x).$$

因为 $\xi>0$，所以 $e^{\xi}>1$，于是 $e^{x}-1>x\cdot1=x$，即 $e^{x}>1+x$。

<!-- ex: 3.1-e2 -->

### 5c 构造辅助函数证存在 $\xi$（检测题 3-1 四、3）

套路：**要证 $f'+\lambda f=0$ 这类，就把 $f$ 乘上 $e^{\lambda x}$ 当辅助函数。**

例：设 $f$ 在 $[a,b]$ 连续、$(a,b)$ 可导，$f(a)=f(b)=0$。证存在 $\xi$ 使 $f'(\xi)+f(\xi)=0$。

设 $F(x)=e^{x}f(x)$。则 $F(a)=F(b)=0$，由罗尔定理存在 $\xi$ 使

$$F'(\xi)=e^{\xi}f(\xi)+e^{\xi}f'(\xi)=e^{\xi}\left[f(\xi)+f'(\xi)\right]=0 .$$

因为 $e^{\xi}\neq0$，所以 $f(\xi)+f'(\xi)=0$。$\blacksquare$

<!-- ex: 3.1-e3 -->

:::practice
辅助函数**看要证的式子反推**：要证 $f'+\lambda f=0$（$\lambda$ 是**常数**）就乘 $e^{\lambda x}$——$f'+f=0$ 乘 $e^{x}$，$f'+2f=0$ 乘 $e^{2x}$。

$\lambda$ 含 $x$ 时不能直接乘 $e^{\lambda x}$，要乘 $e^{\int\lambda(x)\,dx}$：例如要证 $xf'+f=0$，先写成 $f'+\dfrac1xf=0$，此时 $\lambda=\dfrac1x$，乘的是 $e^{\int\frac1x dx}=e^{\ln x}=x$。**"乘 $x$"和"乘 $e^{\lambda x}$"是同一条规则。**
:::

## 速查

### 两个定理

| | 罗尔定理 | 拉格朗日中值定理 |
| --- | --- | --- |
| 条件 | $[a,b]$ 连续、$(a,b)$ 可导、$f(a)=f(b)$ | $[a,b]$ 连续、$(a,b)$ 可导 |
| 结论 | $\exists\xi\in(a,b)$，$f'(\xi)=0$ | $\exists\xi\in(a,b)$，$f(b)-f(a)=f'(\xi)(b-a)$ |
| 图形 | 有水平切线 | 有切线平行于两端连线 |
| 用途 | 证存在 $\xi$、数实根个数 | 证不等式、证恒等式、推单调性 |

### 三个推论

| 推论 | 怎么用 |
| --- | --- |
| $f$ 在区间 $I$ 上可导且 $f'\equiv0$ ⇒ $f$ 在 $I$ 上是常数 | 填空求函数值；证恒等式。**$I$ 必须连通**，否则只能得到"分段常数" |
| $f'>0$ ⇒ 严格递增 | 3.4 节的全部基础 |
| 在 $I$ 上 $\lvert f'\rvert\le M$（$M$ 为**常数**）⇒ $\lvert f(x)-f(y)\rvert\le M\lvert x-y\rvert$ | 证有界、证放大 |

### 五种题型的起手式

| 题目说 | 第一步做什么 |
| --- | --- |
| "满足罗尔定理所有条件的是" | 查连续 → 查可导 → 查两端相等 |
| "求定理中的 $\xi$" | 解 $f'(\xi)=0$，再筛掉区间外的 |
| "$f'\equiv0$，求某点函数值" | 函数是常数，等于已知那点的值 |
| "不求导，说明实根个数" | 找函数的零点区间，每段用一次罗尔 |
| "证明存在 $\xi$ 使…" | 把待证式子凑成某个乘积的导数，取它为辅助函数 |
